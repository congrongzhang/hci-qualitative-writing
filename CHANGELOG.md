# Changelog

All notable changes to this project will be documented here.

## 1.2.0 - 2026-09-22

- Rebuilt the literature-review workflow around source-level explanatory diagnosis, seven failure types, cross-source Gap IDs, counterargument testing, data fit, and verification states.
- Added reusable critical-literature and audience-question assets.
- Added target-reader question planning, reverse outlining, PEEL diagnostics, heading design, cohesion checks, and signal control across the paper workflow.
- Added section-specific communication guidance for titles, abstracts, introductions, Methods, Findings, Discussion, tables, and figures.
- Extended contribution, theory, evidence, reviewer, revision, voice, and submission workflows with the new communication logic.

## 1.1.0 - 2026-09-20

- Added author-confirmed constraints for punctuation, contrastive syntax, copy-ready line structure, citation placement, claim-forward prose, and prohibited vocabulary.
- Added a reusable writing-constraint scanner for Markdown, LaTeX, and text files.
- Updated skill guidance to use compliant terminology and to preserve protected quotations and source metadata.

## 1.0.0 - 2026-09-20

- Added contribution framing, argument architecture, and Findings-to-Discussion workflows.
- Added theory engagement and qualitative evidence-boundary guidance.
- Added claim-evidence-contribution tracing templates.
- Added anti-defensive writing and voice-preservation guidance.
- Added layered reviewer audits, venue-aware checks, and promise-delivery review.
- Added revision-dossier, bilingual-writing, and submission-integrity workflows.
- Added English and Chinese repository documentation.
